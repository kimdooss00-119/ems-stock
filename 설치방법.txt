구급 소모품 관리 - 휴대폰 설치용 파일 (1단계)

[들어있는 파일]
index.html         앱 화면 (시제품)
manifest.json      홈 화면 설치 정보
sw.js              앱 파일 저장(오프라인 대비)
icons/             앱 아이콘 3종

[1] 인터넷 주소(HTTPS)에 올리기 - GitHub Pages 예시 (시험용, 테스트용 가짜 데이터만 사용)
 1. github.com 가입 후 새 저장소(Repository) 만들기 (이름 예: ems-stock)
 2. "Add file > Upload files"로 이 폴더의 파일과 icons 폴더를 모두 올리기
    (zip을 풀고, index.html, manifest.json, sw.js, icons 폴더를 올려야 합니다)
 3. Settings > Pages > Branch를 main, 폴더를 / (root)로 선택 후 Save
 4. 1~2분 뒤 표시되는 주소(https://아이디.github.io/ems-stock/)가 앱 주소입니다.
 ※ 공개 저장소는 누구나 볼 수 있습니다. 실제 업무 데이터나 기관 정보는 올리지 마세요.

[2] 안드로이드 휴대폰에 설치
 1. 크롬으로 위 주소에 접속
 2. 오른쪽 위 점 세 개 메뉴 > "홈 화면에 추가" 또는 "앱 설치"
 3. 홈 화면의 "구급재고" 아이콘으로 실행

[3] 확인할 것
 - 아이콘으로 실행했을 때 주소창 없이 앱처럼 열리는지
 - 상단 "담당자" 칸에 이름 입력 후 입고/출고가 되는지
 - 버튼 크기와 글자가 손에 맞는지

[주의]
 - 데이터는 그 휴대폰의 브라우저 안에만 저장됩니다. 담당자끼리 공유되지 않고,
   브라우저 데이터를 지우면 사라집니다. 공유는 서버 연결 이후 가능합니다.
 - 파일을 수정해 다시 올린 뒤에는 sw.js 맨 위 V 값(현재 ems-v10)을 ems-v11처럼 올려야
   휴대폰에 새 화면이 적용됩니다.
